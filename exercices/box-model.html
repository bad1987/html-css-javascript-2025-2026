CSS Box Model Demonstration

Use browser dev tools to inspect the box model of each element below.

Content Box 1

Width: 200px (content), Padding: 20px, Border: 10px, Total Width: 240px

Content Box 2

Width: 150px (content), Padding: 15px, Border: 5px, Total Width: 170px

Border Box 1

Width: 200px (total), Padding: 20px, Border: 10px, Content Width: 160px

Border Box 2

Width: 150px (total), Padding: 15px, Border: 5px, Content Width: 120px

The key difference: content-box calculates total size as content + padding + border, while border-box includes padding and border in the specified width/height.
