## How to Use

1. **Start the local server:**
   ```bash
   mkdocs serve
   ```
   
2. **Access in browser at:**
   - http://127.0.0.1:8000 (or the URL shown in the terminal)
   
3. **Build static site for distribution:**
   ```bash
   mkdocs build
   ```
   This creates a `site/` directory with all files needed for offline distribution
